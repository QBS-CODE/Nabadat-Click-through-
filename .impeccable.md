## Design Context

### Users
Business analysts, customer success managers, quality teams, and executives across
various industries using a VOC (Voice of Customer) SaaS platform. Desktop-first but
must be responsive. Mixed technical proficiency — from data-savvy analysts to executive
viewers. Arabic-speaking primary audience (Saudi Arabia, Gulf region) with English as
secondary language.

### Brand Personality
**Trustworthy · Data-driven · Clear** — the interface should evoke confidence, competence,
and clarity. Users are making business decisions based on the data presented. The UI must
reduce cognitive load, surface insights quickly, and feel reliable.

### Aesthetic Direction
- **Style**: Data-dense dashboard with clean surfaces. Zain SA-inspired lime green brand identity.
- **Tone**: Professional but approachable — not cold or overly corporate.
- **Theme**: Green-tinted dark mode as an option (not generic grey dark). Light mode default.
- **References**: Zain's clean minimal design, Stripe's dashboard clarity, Linear's polish.
- **Anti-references**: Generic Bootstrap dashboards, overly colorful/busy interfaces,
  "AI slop" aesthetics (cyan-on-dark, neon accents, gradient text).

### Design Principles
1. **Data first** — content and metrics are the hero. Chrome and decoration are secondary.
2. **Clarity over decoration** — every element must earn its place. If it doesn't aid understanding, remove it.
3. **Consistency** — same patterns, same spacing, same behavior everywhere. No special snowflakes.
4. **Bilingual by design** — Arabic and English must both feel native, not adapted as an afterthought.
5. **Accessible by default** — WCAG AA minimum. Color is never the only indicator. Focus rings always visible.

### Color System
- Primary: Zain Lime Green `#95C11F` — brand, energy, action
- CTA/Action: Zain Teal `#00A19A` — calls to action, important interactions
- Dark surfaces: Green-tinted blacks `#0a0f08` / `#141f10` — not neutral grey
- 7 brand color families with 4 shades each (dark, base, lite, ultra-lite)

### Typography
- Zain Regular / Zain Bold (proprietary, with IBM Plex Sans Arabic fallback)
- Fira Code for monospace/numeric data

### Tech Stack
- React 19, TypeScript, Vite, Tailwind CSS v4, shadcn/ui
- Lucide React for icons
- React Router for navigation
- react-i18next for bilingual support
- Recharts for data visualization
